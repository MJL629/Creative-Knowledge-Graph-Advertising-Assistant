# D 演示手册与材料准备

> 用途：比赛 3 分钟演示、内部预演、答辩 Q&A 和用户测试的统一手册。
> 演示环境：mock 模式（无需 API Key），本地 `npm run dev` 后访问 `http://localhost:3000`。

## 1. 演示目标

- 让评委记住：同一个 Brief，因为人的选择不同，长出不同的广告剧情。
- 3 分钟内走完：输入 Brief → 首轮发散 → 用户采用 → 选择生长 → 语义连线 → 剧情收敛 → 来源追溯。
- 只展示核心闭环，不讲解多余细节。

## 2. 三分钟演示脚本

| 时间 | 环节 | 讲解要点 | 屏幕操作 |
|---|---|---|---|
| 0:00-0:20 | 开场痛点 | 短视频广告创意经常“想法很多但落不了地”，AI 一键生成又不可控、不可解释 | 停留在启动页 |
| 0:20-0:40 | 产品定位 | 不是替你写脚本，是把 AI 发散变成一张可编辑、可追溯的创意图谱 | 展示“输入种子 → 创意图谱 → 剧情方案”三步 |
| 0:40-1:00 | 输入 Brief | 用《疯狂水世界》案例，说明只需推广对象 + 碎片想法 | 新建项目，直接使用默认案例 |
| 1:00-1:40 | 首轮图谱 | 三类各 2 个候选节点：创意元素、动机与冲突、剧情事件 | 点击“生成首轮创意图谱”，展示 6 个圆形节点 |
| 1:40-2:10 | 采用与生长 | 采用“水枪国王”，选择继续生长，说明 AI 只生成候选、人决定方向 | 采用节点，选择“深化当前节点”，生成 2 个子节点 |
| 2:10-2:40 | 关系与追溯 | 建立语义关系，展示右侧 Trace / 来源，说明每个节点都有依据 | 点击连接点连线，选中关系标签；展示来源图谱 |
| 2:40-2:55 | 剧情收敛 | 只读取已采用节点和关系，生成约 30 秒剧情 | 点击“收敛为剧情 →”，展示结构化剧情和导出按钮 |
| 2:55-3:00 | 结尾 | “每一个选择，都是故事的分叉口。你的灵感，值得被认真养大。” | 返回图谱，展示版本/来源 |

## 3. 最佳演示路径（预演清单）

1. 打开 `http://localhost:3000`，进入项目库。
2. 点击“＋ 新建项目”，进入 Brief 页（默认已填《疯狂水世界》案例）。
3. 点击“生成首轮创意图谱”，等待 6 个候选节点出现。
4. 点击“水枪国王”节点，右侧点击“✓ 采用”。
5. 继续选中已采用节点，右侧点击“＋ 继续生长”，选择“深化当前节点”，点击“生成候选 →”。
6. 等待 2 个子节点出现，选中一个子节点。
7. 点击右侧“↗ 建立关系”或节点连接点，选择 AI 关系候选并确认。
8. 点击“收敛为剧情 →”，展示 Story 结果。
9. 展示“导出 Markdown / 导出分镜 CSV / 复制全文”。
10. 刷新页面，展示项目恢复，强调会话可恢复。

预演要求：完整走 3 遍以上，记录每步耗时；如果单步超过 10 秒，调整讲解节奏或改为提前预生成。

## 4. 失败预案

| 风险 | 处理 |
|---|---|
| AI 生成慢或超时 | 使用 mock 模式；演示前把候选预生成并保存在当前项目 |
| 接口返回 500/网络失败 | 页面会显示错误提示，不白屏；重新点击“生成首轮创意图谱”重试 |
| 出现 409 冲突 | 说明“多人同时编辑时系统会重新加载最新图谱”，并演示恢复 |
| 刷新后项目丢失 | 本地 memory 模式只在当前进程内有效；正式演示改用 PostgreSQL 或演示前不重启服务 |
| 页面异常 | 准备好录屏版演示视频作为兜底 |

## 5. 答辩 Q&A 清单

### 产品价值

- Q：和 ChatGPT 直接生成脚本有什么区别？
  - A：ChatGPT 是一次性生成的黑箱；我们把创意拆成可交互的知识图谱，人决定采用/排除/连线，AI 负责候选和收敛，结果可解释、可追溯、可局部修改。
- Q：图谱会不会太复杂，用户不会用？
  - A：连线是可选操作，不连线也能完成；至少采用一个节点即可收敛；认知负担是我们最重要的验收指标之一。

### 技术

- Q：AI 在这里真的不可替代吗？
  - A：去掉 AI 后只剩手工编辑，发散成本大幅上升；AI 负责结构化发散、关系推荐和剧情收敛，业务规则负责确定性提交和一致性约束。
- Q：如何保证剧情只使用用户已采用的内容？
  - A：剧情收敛只读取已采用节点和已采用关系，未采用/已排除内容不会进入生成上下文；并有引用校验。
- Q：并发编辑怎么办？
  - A：Graph Commit 使用乐观 revision，冲突返回 409，前端重新加载最新图谱。

### 商业

- Q：谁付费？
  - A：先验证短视频主创/策划和内容团队；商业化路径是个人订阅 + 团队版 + 垂直行业方案。
- Q：为什么是短视频广告，而不是写小说/剧本？
  - A：短视频广告周期短、频次高、需要快速试多条方向，正好匹配“发散—选择—收敛”的工作流。
