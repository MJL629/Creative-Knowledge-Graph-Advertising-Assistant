# D 验收清单（Product & Quality）

> 用途：D 在 mock 模式下逐条验收完整 Demo，作为 Quality Owner 的过程交付物。
> 使用方式：每条记录 `通过 / 不通过 / 问题描述 / 责任人`，不通过项当天进入缺陷清单。

## 运行方式

1. `npm ci`
2. 复制 `.env.example` 为 `.env`，设置 `CREATIVE_MODEL_PROVIDER=mock`
3. `npm run dev`
4. 用《疯狂水世界》案例走完整流程
